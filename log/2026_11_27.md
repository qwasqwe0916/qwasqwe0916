## 추가 기능 (방, 팀 나가기, 로그인 개선)

마감일 확인: **12월 6일**

### 1. 서버·사이트 다시 열기
* 2주 만에 작업 재개: `main` 받기 → Supabase 프로젝트 일시 정지 여부 확인(무료 플랜은 일주일 미사용 시 정지) → MySQL 실행 → 서버(`server`)·화면(`client`) 실행
* 모바일로 보는 방법 정리
  * 화면 배치 확인: 브라우저 개발자 도구의 모바일 보기 (Chrome `⌘ + Shift + M`, Safari 반응형 디자인 모드)
  * 실제 휴대폰 접속: 같은 Wi-Fi + `npm run dev -- --host` → 현재는 화면이 서버를 `localhost:3000`으로 불러서 동작하지 않음, 화면 다듬기 단계에서 개발 서버 프록시로 해결 예정
* 모바일 최적화는 나중에 하기로 결정

### 2. 기능 아이디어 논의: 수업 내 조 편성
* 아이디어: 교양 수업 등에서 교수님이 "방"을 열면, 그 수업 학생끼리 모집글을 올려 조를 구하는 기능
* 비교한 방안
  * A. 수업 방 + 기존 기능 재사용 (참여 코드, 방 안의 모집글)
  * B. 관리자 기능 추가 (팀 인원 범위, 마감일, 편성 현황판, 한 방 한 팀, CSV)
  * C. 시간표 기반 (학교 수업 데이터를 구할 수 없어 제외)
* **결정: A + B 기능.** 전체 게시판은 그대로 두고 방을 추가로 만들 수 있게 함 (자율 스터디는 전체 게시판에서)
* 교수님 확인은 하지 않고 방을 만든 사람이 관리자
* 팀에서 나가는 기능이 없던 점을 발견 → **팀 나가기** 추가, 방 나가기는 팀을 먼저 나가야 한다는 팝업으로 안내

### 3. 방 (R30 ~ R34, R36)
* DB: `rooms`(방, 참여 코드 UNIQUE, 팀 인원 범위 CHECK, 마감일), `room_members`(방 ↔ 회원 M:N, 역할), `posts.room_id`(NULL이면 전체 게시판) 추가
* 서버 (`src/routes/rooms.js`, `src/rooms.js`)
  * 방 만들기(만든 사람 = 관리자), 내 방 목록, 참여 코드로 참여(대소문자 무관, 이미 참여 중이면 그대로)
  * 방 정보, 설정 수정·참여 코드 재발급·방 삭제(관리자)
  * 방 나가기: 관리자 불가, 팀 소속이면 409 + 안내, 아니면 지원 취소·팀 미구성 모집글 삭제
  * 편성 현황(관리자): 팀별 팀원, 인원 부족 표시, 미편성 참여자(`NOT EXISTS`), CSV 내려받기(UTF-8 BOM)
* 방 글 규칙
  * 방 참여자에게만 보임 (목록, 상세, 댓글, 지원, 작성자 프로필 모두 검사), 전체 게시판에는 나오지 않음
  * 익명 글·익명 댓글 불가, 모집 인원은 (최대 인원 - 1)까지, 카테고리 기본값 "팀 프로젝트"
  * 관리자는 팀 편성에 참여하지 않음 (아래 5번에서 "항상 제외"로 확정)
  * 마감일이 지나면 새 모집글·지원 불가 (팀 구성은 가능)
* 한 방 한 팀 (R33)
  * 팀 소속자는 같은 방에서 지원·글쓰기 불가, 다른 팀 소속자는 수락·팀 구성 불가
  * 팀 구성 시 방 행을 잠그고(동시 구성 방지) 인원 범위와 중복 소속을 검사
  * 팀이 구성되면 새 팀원들의 같은 방 대기 지원은 취소, 수락 지원은 거절, 본인의 다른 모집글은 모집완료
* 화면
  * 위쪽 메뉴 "내 방": 참여 중인 방 목록, [방 만들기], [코드로 참여](관리자에게 정보 공개 안내 후 참여)
  * 방 화면: 방 정보, 관리자에게 참여 코드 표시, 방 게시판(전체 게시판과 같은 목록·필터), 내가 소속된 팀 안내, [방 나가기]
  * 관리자 탭: 편성 현황(팀·미편성·CSV), 설정(방 설정, 참여 코드 재발급, 방 삭제)
  * 방 글쓰기: 방 이름 안내, 익명 체크박스 숨김, 모집 인원 상한 표시
  * 게시글 상세·마이페이지에 방 이름 표시

### 4. 팀 나가기 (R35)
* `POST /api/posts/:id/team/leave`: 수락된 팀원만 (지원 기록 삭제, 팀 게시판 글은 유지)
* 작성자는 나갈 수 없고 게시글 삭제로 팀 해체
* 마지막 팀원이 나가면 팀 구성 취소 → 작성자가 다시 모집중으로 바꿔 재모집 가능
* 팀 페이지 아래 [팀 나가기] (작성자에게는 해체 안내 문구)

### 5. 테스트 후 수정
* 방 글의 카테고리를 **"팀 프로젝트"로 고정**
  * 방 글쓰기 화면에서 카테고리 선택칸 제거, 서버가 방 글의 카테고리를 항상 "팀 프로젝트"로 저장 (다른 값을 보내도 무시)
  * 방 게시판에서 카테고리 탭(전체/공모전/스터디/팀 프로젝트)과 글의 카테고리 배지 제거, 게시글 상세·마이페이지에서도 방 글은 방 이름 배지만 표시
* **관리자는 항상 팀 편성에서 제외**
  * 방 만들기·설정의 "나도 팀 편성 대상에 포함" 선택 제거, DB의 `rooms.manager_in_pool` 컬럼 삭제
  * 관리자는 자기 방에서 글쓰기·지원 불가 (댓글은 가능), 편성 현황의 대상·미편성 목록에서 항상 제외
* 요구사항 R31·R32, ERD 수정

### 테스트 (클라우드: 가짜 Supabase + MySQL)
* 접근 권한: 방 참여자가 아닌 사람은 방 게시판·방 글·댓글 403, 전체 게시판에 방 글이 나오지 않음
* 방 규칙: 인원 범위 오류, 관리자(편성 제외) 글쓰기 403, 익명 방 글 400, 모집 인원 상한 400, 익명 댓글 자동 해제
* 팀 구성: 최소 인원 미달 400, 구성 후 새 팀원의 대기 지원 취소·다른 모집글 모집완료, 팀 소속자 글쓰기 400
* 방 나가기: 팀장 409(안내 문구), 관리자 400 / 팀 나가기: 작성자 400, 마지막 팀원이 나가면 팀 구성 취소
* 편성 현황·CSV: 관리자만 가능, 미편성 참여자 표시, CSV에 BOM 포함
* 방 삭제 시 방 글·참여자·지원 내역 연쇄 삭제
* 두 계정 브라우저: 방 만들기 → 코드로 참여 → 방 글쓰기 → 수락·팀 구성 → 관리자 편성 현황·CSV → 팀장의 방 나가기 팝업
* 테스트 후 수정분: 방 글 카테고리 고정(다른 카테고리를 보내도 팀 프로젝트로 저장), 관리자 글쓰기·지원 403·댓글 가능, 편성 현황에서 관리자 제외
* 로그인: 아이디만 입력 시 `@seoultech.ac.kr` 자동 부착, 전체 주소 붙여넣기 시 도메인 자동 제거, @ 포함·허용되지 않는 문자 안내
