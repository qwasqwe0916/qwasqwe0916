## 환경 구축

### 클로드 코드 사용 환경 정리
* VS Code의 Claude Code 확장(사이드 채팅)을 OmniRoute와 연결
  * 인증 토큰 값 오류(non-ASCII 문자) 및 모델 지정 오류(`Ambiguous model`) 해결
  * OmniRoute 대시보드에서 Claude 제공자 계정 연결
* 답변 언어를 한국어로 설정

### 프로젝트 구조 결정 (README 반영)
* 로그인/이메일 인증은 **Supabase Auth**, 서비스 핵심 데이터는 **MySQL**로 역할 분담
* 개발 계획을 단계별로 재구성
  * 1단계 개발 환경 준비 → 2단계 DB 설계 및 구축 → 3단계 기능 단위 개발(프론트엔드 + 백엔드) → 4단계 통합 테스트 및 발표 준비
  * 기능별 작업 순서(브랜치 → 구현 → 확인 → 점검 → PR → 기록) 정리
* 관리 도구(MySQL Workbench 등)는 필수가 아니므로 선택 사항으로 둠

### Supabase 설정
* 프로젝트 생성 (Region: Northeast Asia (Seoul))
* Email 로그인, 신규 가입 허용, 이메일 확인 활성화
* Magic Link / Confirm signup 메일 템플릿을 6자리 인증번호(`{{ .Token }}`) 방식으로 변경
* Gmail SMTP 연결 (앱 비밀번호 사용) 및 발송 한도(Rate Limits) 조정
* Site URL을 `http://localhost:5173`으로 설정
* 초대 메일 발송 테스트 → 학교 메일 수신 확인

### 프로젝트 기본 세팅
* `.gitignore` 추가 (`.env`, `node_modules/`, `.DS_Store` 제외)
* `client/.env`, `server/.env` 작성 (Supabase URL/anon 키, MySQL 접속 정보)
* MySQL에 `campus_matcher` 데이터베이스 생성 (utf8mb4)
* 서버(`server/`): Express + mysql2 + dotenv + cors + supabase-js, nodemon
  * `/api/health`로 MySQL 접속 확인 완료
* 화면(`client/`): Vite + React (ESLint), supabase-js
  * `src/lib/supabase.js`에 Supabase 연결 설정
  * `http://localhost:5173` 기본 화면 실행 확인
